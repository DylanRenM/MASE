---
本次对话梳理了4个核心业务流程拓扑：

**B001: 文件选择与校验流程**
1. 用户选择文件 → 系统校验文件格式
2. 文件格式为Word(.docx)或TXT(.txt) → 文件就绪等待播放
3. 文件格式为其他格式 → 弹出错误提示 → 回到选择文件状态
4. 文件就绪等待播放 → 用户点击播放按钮

**B002: 触发朗读与循环播放流程**
1. 用户点击播放按钮 → 系统开始朗读
2. 系统开始朗读 → 循环朗读至末尾 → 从头开始

**B003: 暂停与继续流程**
1. 用户点击暂停按钮 → 朗读停止，记录位置
2. 朗读停止，记录位置 → 用户点击继续按钮（恢复朗读）或用户选择新文件（重置到文件就绪状态）
3. 用户点击继续按钮 → 从暂停位置恢复朗读

**B004: 定时停止流程**
1. 用户设定朗读时长 → 系统开始计时
2. 系统开始计时 → 计时到达设定时长 → 系统自动中止朗读

核心流程总结：用户选择文件→系统校验格式→文件就绪→用户点击播放→开始循环朗读→用户可随时暂停/继续，或预设时长自动停止。暂停状态下选择新文件会重置到文件就绪状态。
---
更新了触发朗读与循环播放的GWT场景，包含4个场景：正常路径播放有效文件（增加非英文字符过滤步骤）、正常路径播放至文件末尾并循环、异常路径播放时文件被外部修改、边界路径文件内容全部为非英文。
