## 2. 产品目标

为 macOS 用户提供一个离线英文听读工具。用户选择本地文本文件后，应用提取其中的英文内容，通过 macOS 系统语音持续循环朗读，并提供暂停、继续、停止、速度切换、定时停止和进度展示能力。

## 3. 用户与核心场景

### 3.1 用户角色

- 普通用户：希望通过反复收听英文材料进行语言输入或“磨耳朵”训练。

### 3.2 核心流程

1. 用户选择一个受支持的本地文件。
2. 系统校验文件类型、大小和可读性。
3. 系统提取文本、过滤非英文内容并进入就绪状态，不自动播放。
4. 用户可设置三档速度及可选的定时时长。
5. 用户点击播放，系统从文件开头朗读。
6. 用户可暂停、继续或停止；播放到末尾后自动从头循环。
7. 设置了定时的会话在累计实际朗读时间达到设定值后自动停止。

## 4. 平台与技术约束

- MVP 仅支持 macOS，最低版本为 macOS 13 Ventura。
- MVP 采用原生 SwiftUI 实现。
- TTS 使用 macOS 系统语音能力。
- 使用系统当前默认的英文语音，不提供音色或发音人选择。
- MVP 离线运行，不依赖网络服务。
- 后续 Windows、iOS、Android 支持不属于本次 MVP 范围。

## 5. 功能需求

### F001 文件选择与校验

1. 支持 `.txt`、`.docx`、`.pdf` 文件。
2. 不支持旧版 `.doc` 文件和其他未列出的格式。
3. 单文件大小不得超过 20MB。
4. PDF 仅支持可直接提取文本的文档，不支持扫描件或 OCR。
5. 选择有效文件后显示文件名并进入就绪状态，不自动朗读。
6. 文件不存在、不可读、损坏、格式不支持、超过大小限制或无法提取文本时，系统必须显示明确错误，并且不得进入播放状态。
7. 选择新文件会清除上一文件的暂停位置、进度和计时状态，新文件从头就绪。

### F002 英文内容过滤

1. 系统只将英文字母 `A-Z`、`a-z` 和必要的单词间空白交给 TTS。
2. 数字、标点符号、特殊字符及其他语言文字全部过滤。
3. 连续空白须规范化，避免产生无意义的停顿。
4. 空文件或过滤后没有英文内容的文件不得开始朗读，并须显示对应提示。
5. 文件内容始终按纯文本处理，不得执行其中的脚本、标记或其他代码。

### F003 播放与循环

1. 用户点击播放按钮后，系统从文件开头或当前已记录位置开始朗读。
2. 朗读至文件末尾后，系统自动回到第一段继续朗读，播放状态保持不变。
3. MVP 始终采用持续循环模式，不提供循环次数设置。
4. 快速重复点击播放不得启动多个并行 TTS 会话。

### F004 暂停与继续

1. 播放状态下点击暂停，系统暂停 TTS，并记录当前英文段落和字符位置。
2. 暂停期间定时器冻结，不累计暂停时间。
3. 点击继续后，从记录位置恢复朗读并继续累计定时。
4. 暂停期间可以调整朗读速度；继续后使用新速度从记录位置恢复。

### F005 独立停止

1. 播放或暂停状态下均提供独立的停止按钮。
2. 点击停止后，系统立即终止 TTS，停止并清除本轮计时，将进度重置到文件开头。
3. 停止后保留当前文件并回到就绪状态，用户可再次点击播放。

### F006 朗读速度

1. 提供“慢”“正常”“快”三个互斥档位。
2. 默认档位为“正常”。
3. 空闲、文件就绪或暂停状态下可以切换速度。
4. 播放状态下速度控件不可用。
5. 各档位与系统 TTS 速率的具体映射由技术可行性 POC 验证，但必须保证三个档位有可感知且稳定的速度差异。

### F007 定时停止

1. 定时设置可留空；留空表示不限时朗读。
2. 定时时长仅接受整数分钟，最小 1 分钟，最大 240 分钟。
3. 非整数、超出范围或其他非法输入必须被拒绝，并显示明确提示。
4. 定时器只累计实际朗读时间，暂停期间冻结，继续后恢复。
5. 累计实际朗读时间达到设定值后，系统自动停止 TTS、清除本轮计时并将进度重置到文件开头。
6. 定时停止后保留当前文件并回到就绪状态。

### F008 朗读进度

1. 播放和暂停状态下显示总体朗读百分比。
2. 同时显示“当前英文段落/英文总段落数”。
3. 暂停时进度保持不变；继续时从该位置推进；停止或定时到期后重置到开头。
4. 循环进入下一轮时，进度从开头重新计算。

### F009 源文件变化处理

1. 播放期间源文件被外部修改时，系统必须在 5 秒内检测到变化。
2. 系统提示用户选择“重新加载”或“继续当前内容”。
3. 选择重新加载时，系统重新解析文件并从新内容开头播放。
4. 选择继续时，本轮继续使用已加载到内存的旧内容。
5. 文件在就绪后被移动、删除或变得不可读时，点击播放须提示读取失败并回到空闲状态。

### F010 会话生命周期

1. MVP 不持久化已选文件、朗读位置、暂停状态或剩余时间。
2. 应用关闭并重新打开后始终回到空闲初始状态。

## 6. 状态模型

应用至少包含以下业务状态：

- `idle`：未加载有效文件；
- `ready`：文件已加载，等待播放；
- `playing`：正在朗读并累计有效朗读时间；
- `paused`：朗读和计时均已暂停；
- `reloading`：用户确认后重新读取已修改文件；
- `error`：展示错误后回到可恢复的 `idle` 或 `ready` 状态。

关键状态转换：

- `idle → ready`：成功选择并解析文件；
- `ready → playing`：点击播放；
- `playing → paused`：点击暂停；
- `paused → playing`：点击继续；
- `playing/paused → ready`：点击停止；
- `playing → ready`：定时到期；
- `playing → reloading → playing`：源文件变化且用户选择重新加载；
- 任意文件已加载状态选择新文件：清除旧会话后进入新文件的 `ready` 状态。

## 7. 非功能需求

### 7.1 响应与稳定性

- 支持的 20MB 以内文件不得导致应用崩溃或界面长期无响应。
- 源文件修改检测延迟不得超过 5 秒。
- 重复或快速交替的播放控制操作不得造成界面状态与 TTS 状态不一致。

### 7.2 安全与隐私

- 文件只在本地处理，不上传到网络。
- 文档内容按数据处理，不执行脚本、宏或嵌入对象。
- 解析失败必须安全终止，不得进入不一致的播放状态。

### 7.3 可测试性

- 文件解析、英文过滤、状态机、计时器、源文件监控和 TTS 适配器必须具备独立测试边界。
- 系统 TTS 和时间来源必须可替换为测试替身，以支持确定性的自动化测试。

## 8. MVP 范围外

- Windows、iOS、Android 平台；
- 旧版 `.doc` 文件；
- 扫描 PDF、OCR；
- 中文或其他语言朗读；
- 音色、发音人或自定义 TTS 引擎选择；
- 循环次数设置；
- 文本编辑、格式转换、多文件管理；
- 文件、进度、播放会话的跨启动恢复；
- 云服务、账户及网络同步。

## 9. 验收场景

### P0：核心业务门禁

#### S001 选择并播放 TXT

- **Given** 用户处于空闲状态，且存在一个 20MB 以内、包含英文内容的 `.txt` 文件
- **When** 用户选择文件并点击播放
- **Then** 系统显示文件名，从第一段开始朗读，并显示百分比和段落进度

#### S002 选择并播放 DOCX

- **Given** 存在一个可解析且包含英文内容的 `.docx` 文件
- **When** 用户选择文件并点击播放
- **Then** 系统提取正文英文内容并正常朗读

#### S003 选择并播放文本型 PDF

- **Given** 存在一个可直接提取英文文本的 `.pdf` 文件
- **When** 用户选择文件并点击播放
- **Then** 系统提取英文内容并正常朗读

#### S004 循环播放

- **Given** 系统正在朗读
- **When** 朗读到最后一个英文段落末尾
- **Then** 系统从第一段继续朗读，且播放状态保持不变

#### S005 暂停与继续

- **Given** 系统正在朗读且启用了定时
- **When** 用户暂停一段时间后继续
- **Then** 系统从暂停位置恢复，暂停期间不计入定时时长

#### S006 停止并重置

- **Given** 系统正在播放或暂停
- **When** 用户点击停止
- **Then** 系统立即停止朗读、清除计时、重置到文件开头，并保留文件为就绪状态

#### S007 定时停止

- **Given** 用户设置了 1 至 240 之间的整数分钟并开始播放
- **When** 累计实际朗读时间达到设定值
- **Then** 系统自动停止并重置到文件开头

#### S008 不限时播放

- **Given** 用户未设置定时时长
- **When** 用户开始播放
- **Then** 系统持续循环，直至用户暂停或停止

#### S009 非英文内容过滤

- **Given** 文件同时包含英文字母、数字、标点及其他语言字符
- **When** 系统准备 TTS 内容
- **Then** 送入 TTS 的内容只包含英文字母和必要空白

#### S010 无英文内容

- **Given** 文件为空或过滤后没有英文内容
- **When** 用户尝试播放
- **Then** 系统不启动 TTS，并显示无可朗读内容提示

### P1：重要辅助场景

#### S011 文件修改提示

- **Given** 系统正在播放，源文件被外部修改
- **When** 修改发生
- **Then** 系统在 5 秒内提示重新加载或继续旧内容

#### S012 暂停后切换速度

- **Given** 系统已暂停并记录位置
- **When** 用户选择新的速度并继续
- **Then** 系统使用新速度从记录位置恢复朗读

#### S013 非法文件被拒绝

- **Given** 文件格式不支持、超过 20MB、损坏或不可读
- **When** 用户选择该文件
- **Then** 系统显示对应错误，且不进入播放状态

#### S014 扫描 PDF 被拒绝

- **Given** PDF 不包含可直接提取的文本
- **When** 用户选择该 PDF
- **Then** 系统提示不支持扫描件或 OCR，且不进入播放状态

#### S015 重复控制保持一致

- **Given** 系统处于可播放或播放状态
- **When** 用户快速重复点击播放、暂停或继续
- **Then** 系统只维持一个 TTS 会话，最终业务状态与最后一个有效操作一致

### P2：边缘与探索场景

- 特殊字符及超长本地路径；
- 恰好在文件循环边界触发定时停止；
- 应用播放或暂停时被强制关闭；
- 不同 TXT 编码及复杂 DOCX/PDF 排版的兼容性探索。

## 10. 成功标准

1. P0 E2E 场景 100% 自动化通过。
2. API/模块契约测试 100% 通过。
3. 支持的三类文件在正常路径下均能提取英文内容并朗读。
4. 暂停位置、计时冻结、停止重置和循环行为符合本规格书。
5. 播放期间文件变化能在 5 秒内提示。
6. 文件内容不离开本机，且任何文档内容都不会作为代码执行。
