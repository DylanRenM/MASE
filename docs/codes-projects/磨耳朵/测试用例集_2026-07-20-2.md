## 1. 测试口径

- MVP 平台：macOS 13+。
- 支持格式：`.txt`、`.docx`、文本型 `.pdf`；不支持 `.doc`、扫描 PDF 和 OCR。
- 单文件上限：20MB。
- TTS 输入只保留英文字母及必要空白。
- 定时范围：1–240 整数分钟；留空为不限时；暂停时间不计入。
- 循环次数不可配置，始终持续循环直至停止或定时到期。
- P0 E2E 必须 100% 自动化通过；API/模块契约测试必须 100% 通过。

## 3. 契约测试候选

以下内容在 Design L2 转换为 API/模块级 DbC 契约，并在 Build 阶段实现自动化测试：

| 契约 ID | 模块 | 前置条件 | 后置条件 / 不变式 |
|---------|------|----------|-------------------|
| CT-001 | DocumentLoader | URL 可访问 | 成功返回有序段落，或返回类型明确的失败；不产生半加载会话 |
| CT-002 | FilePolicy | 文件元数据可读取 | 仅接受允许扩展名且大小不超过 20MB 的常规文件 |
| CT-003 | EnglishTextFilter | 输入为任意 Unicode 文本 | 输出只匹配英文字母与规范化空白；函数无副作用 |
| CT-004 | ReadingSession | 收到任意用户控制事件 | 同一时刻最多存在一个活动 TTS 会话；状态转换合法 |
| CT-005 | ReadingTimer | 配置为空或 1–240 整数分钟 | 只在 `playing` 累计；`paused` 时数值不变；到期只触发一次 |
| CT-006 | SpeechEngine | 输入为过滤后的非空文本 | 回调中的段落/字符位置单调推进，停止后不继续发送进度 |
| CT-007 | SourceFileMonitor | 播放文件仍可访问 | 文件变化在 5 秒内最多触发一次待处理提示 |

## 5. E2E 环境隔离要求

- 每个 E2E spec 在 `beforeAll` 创建文件系统与配置快照。
- 测试样本全部位于测试沙箱，不直接修改用户文件。
- `afterAll` 恢复快照并验证目录、文件与配置一致；恢复失败即阻断后续测试。
- 真实分钟级定时只保留最小必要的端到端冒烟验证，其余计时行为通过可注入时钟进行确定性测试。
