# 设计文档：布局重构 — 右侧结果面板

> 关联项目：StoryPoint Estimator AI v2.1 | 2026-07-21

## 1. 动机

当前问题：单个需求估算后，结果内容过长（依据 + 参考基准 + 复杂度 + 风险提示），将下方的批量估算和基准管理工具推出屏幕之外，用户需要反复滚动才能操作。

目标：估算结果不再占用主工作区的垂直空间，通过右侧面板独立展示。

## 2. 布局设计

```
┌────────────────────────────────────┬──────────────────────────┐
│ StoryPoint                      ● │  估算结果 / 批量汇总       │
├────────────────────────────────────┤                          │
│                                    │  ┌────────────────────┐ │
│  估算表单                          │  │ [ 5 ]  置信 3–8     │ │
│  [标题]  [描述]  [开始估算]         │  │                    │ │
│                                    │  │ 依据: 复杂度中等...  │ │
│  ── 批量估算 ──                     │  │                    │ │
│  [下载模板] [上传文件]              │  │ ── 参考基准 ──       │ │
│                                    │  │ S1  3点  67%       │ │
│  ── 基准管理 ──                     │  │ S3  2点  54%       │ │
│  ▶ 12条已加载                      │  │                    │ │
│  [下载] [上传] [替换] [追加]         │  │ ── 复杂度特征 ──     │ │
│                                    │  │ 前端:1  后端:2 ... │ │
│  (主区内容固定，不被结果推走)         │  │                    │ │
│                                    │  │ ⚠️ 风险提示...      │ │
│                                    │  │              (滚动) │ │
│                                    │  └────────────────────┘ │
└────────────────────────────────────┴──────────────────────────┘
```

### 2.1 网格参数

- 主工作区：`1fr`，最大宽度 `720px`
- 右侧面板：`380px`，`overflow-y: auto`，`border-left: 1px solid divider`
- 头部：固定 56px 高度

### 2.2 面板内容自适应

| 状态 | 面板内容 |
|------|----------|
| 无估算 | 占位提示："请在上方输入需求并开始估算" |
| 单个估算完成 | 大数 + 置信区间 + 依据 + 参考基准 + 复杂度表 + 风险提示（可滚动） |
| 批量估算完成 | 标题"批量估算结果 (N条)" + 汇总表（ID/标题/点数/置信），点击行展开详情 |

### 2.3 文本处理

- 估算依据、风险提示使用 `white-space: pre-wrap` + `word-break: break-word`
- 面板内部 `overflow-y: auto`，最大高度 `calc(100vh - 56px)`
- 面板内表格列宽自适应，不强制固定宽度

## 3. 交互动效

结果面板内容切换时使用淡入过渡：
- `opacity: 0 → 1`，持续时间 250ms
- 主工作区无任何位移变化

## 4. API 变更

| 变更 | 说明 |
|------|------|
| 移除 `GET /history` | 前端不再单独请求历史 |
| 保留 DB 写入 | `estimate_service` 仍写入 `estimate_history` 表（审计保留） |
| `POST /batch/estimate` 响应变更 | 返回 JSON（而非直接下载文件），包含 `{status, results: [...], download_url}` |

### 4.1 批量估算流程调整

```
旧：POST → 直接返回 Excel blob 下载
新：POST → 生成结果 Excel 保存到临时文件
    → 返回 JSON {status: "ok", rows: [...], download_token: "..."}
    → 前端在右侧面板渲染汇总表
    → 面板底部显示 [下载 Excel] 按钮
    → 点击 GET /batch/download?token=xxx 返回 blob 下载
```

**Token 存储**：服务端使用内存字典 `_batch_results: dict[str, str]`（token → 临时文件路径）。
Token 生成：`uuid4().hex[:12]`，有效期至下载或服务重启。

`/batch/estimate` 响应格式：

```json
{
  "status": "ok",
  "count": 3,
  "download_token": "a1b2c3d4e5f6",
  "rows": [
    {
      "id": "B1", "title": "微信扫码登录", "description": "...",
      "estimate": 5, "confidence_min": 3, "confidence_max": 8,
      "reasoning": "...", "risk_notes": "..."
    }
  ]
}
```

新增 `GET /batch/download?token=<token>`，读取临时文件并返回 Excel 下载，下载后清理临时文件。

### 4.2 面板内容切换规则

| 触发事件 | 面板行为 |
|----------|----------|
| 单个估算完成 | 清空当前面板内容，渲染单个结果 |
| 批量估算完成 | 清空当前面板内容，渲染批量汇总表（每行可点击展开详情到同一面板内） |
| 页面初始加载 | 显示占位提示 |
| 批量行点击 | 在该行下方展开 / 折叠该条目的详细依据和风险提示 |
| 面板溢出 | 整体 `overflow-y: auto`，面板内独立滚动，不影响主区 |
